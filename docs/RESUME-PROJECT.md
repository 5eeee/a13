# Тексты для резюме — проект «Бюро А13»

## Кратко (1–2 предложения)

Корпоративный сайт и админ-панель для бюро светопрозрачных конструкций: витрина услуг и проектов, калькулятор стоимости, формы заявок, CMS с редактированием контента и реестром заявок. Фронтенд на React, бэкенд на Node.js и PostgreSQL, развёртывание на VPS (Nginx, PM2).

---

## Описание для блока «Опыт» / «Проекты»

**Сайт и CMS «Бюро А13»** (a13bureau.ru)

Разработал и вывел в продакшен полноценный корпоративный сайт с личным кабинетом администратора.

**Что сделано на сайте:**
- Главная, услуги, портфолио проектов, блог, FAQ, контакты с картой (Яндекс.Карты).
- Калькулятор ориентировочной стоимости остекления с отправкой заявки на сервер.
- Несколько точек сбора заявок: контакты, всплывающая форма, плавающая кнопка.
- Адаптивная вёрстка, анимации, cookie-баннер, базовая аналитика (Яндекс.Метрика).

**Админ-панель:**
- Управление проектами, новостями, отзывами, партнёрами, блоком «О компании», цифрами на главной.
- Rich-text редактор (TipTap), загрузка и обрезка изображений, drag-and-drop сортировка списков.
- Реестр заявок с фильтрами (калькулятор / формы / попап), статусами, пагинацией, звонком и копированием текста заявки.
- Настройки маркетинга, двухфакторная авторизация (TOTP), защита API ключом.

**Бэкенд и инфраструктура:**
- REST API на Express: документы CMS в PostgreSQL, приём заявок, rate limit, уведомления в Telegram и на email (SMTP).
- Сборка фронта Vite, проксирование `/api` через Nginx, процесс API в PM2, SSL Let's Encrypt.
- Скрипты деплоя по SSH, локальный Docker для PostgreSQL, service worker для статики.

## Стек (для резюме списком)

**Фронтенд:** React 18, React Router 7, TypeScript, Vite 6, Tailwind CSS 4, Motion (анимации), TipTap / ProseMirror (редактор), @dnd-kit (перетаскивание), lucide-react (иконки), Sonner (уведомления), react-easy-crop.

**Бэкенд:** Node.js, Express 4, PostgreSQL (драйвер `pg`), dotenv, CORS, Nodemailer, otplib (2FA).

**Инфраструктура и прочее:** Nginx, PM2, Docker Compose (PostgreSQL), Bash (deploy.sh), PowerShell (локальный запуск), Service Worker, Яндекс.Метрика, виджет Яндекс.Карт, Sharp (обработка изображений в скриптах).
